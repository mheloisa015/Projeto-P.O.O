# 📌 Sistema de Cadastro de Defeitos em Peças — Protótipo

Este projeto é um **protótipo de sistema para registro de defeitos em peças** em uma linha de produção, desenvolvido com foco em melhorar a rastreabilidade de falhas e apoiar decisões na área industrial.

---

## 🛠️ Tecnologias Utilizadas

- **Java** (Programação Orientada a Objetos)
- **MySQL** (Banco de Dados Relacional)
- **Swing** (Interface Gráfica)

---

## 🎯 Objetivo

O sistema foi idealizado para:

- ✅ Registrar defeitos de forma estruturada, evitando perda de informações;
- ✅ Padronizar e centralizar os dados, facilitando a rastreabilidade e análise de falhas;
- ✅ Apoiar a tomada de decisões com base em informações organizadas e acessíveis.

---

## 📈 Benefícios Esperados

- Melhoria na organização das informações da produção;  
- Otimização da análise de falhas recorrentes;  
- Redução de retrabalho por falta de rastreabilidade.

---

## 📚 Aprendizados

Mesmo sendo um protótipo inicial, o projeto proporcionou aprendizados importantes, como:

- Integração prática entre Java e MySQL;
- Aplicação dos princípios da Programação Orientada a Objetos;
- Importância da tecnologia na **melhoria contínua dos processos industriais**.

---

## 🚀 Próximos Passos (Sugestões)
